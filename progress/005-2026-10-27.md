### Session 005 — 2026-10-27

#### Summary

feat-002: GitHub issue ingestion, resumable and pseudonymized.

#### Done

- Domain: `Issue`, `Comment`, `DuplicateLink` entities; `IssueSource` / `IssueStore` interfaces; `Pseudonymizer` (keyed HMAC pseudonyms for logins and @mentions outside code, emails/URLs/version pins untouched).
- Infrastructure: `GitHubGraphQLSource` (oldest first, 50 per page, waits for the rate-limit reset when under 100 points, retries transient failures with backoff) over a stdlib `urllib` transport; `JsonlIssueStore` (`data/github/<owner>__<name>/issues.jsonl` plus an atomic `state.json` cursor; readers keep the last record per issue).
- Service `ingest_issues` and CLI `python -m issue_triage ingest owner/repo [--max-pages N] [--restart]`; token from `ISSUE_TRIAGE_GITHUB_TOKEN` or `gh auth token`.
- The first full run against astral-sh/uv stopped on a `ConnectionResetError` mid-read that the transport did not treat as transient. Fixed (any `OSError` / `HTTPException` after `HTTPError` is now transient) and covered by tests.
- 41 tests (24 new). README, ARCHITECTURE and `.env.example` updated.
